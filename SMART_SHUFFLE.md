# Account 2: Movies · Smart Shuffle (fifth catalog)

**Independent of all previous rows.** The new catalog is appended after TV Up Next, Home Releases, Upcoming Movies, and Upcoming TV; the root anime addon is unchanged. The existing Account 2 manifest URL remains the same.

## What the row does

- Source: the **entire Account 2 Simkl movie Plan to Watch list**, not a six-month-filtered subset.
- Every hour, the existing GitHub Actions build fetches the list and reuses the private TMDB release-date cache generated by the existing Home Releases row.
- A **featured** item has a *first known* digital or physical release in the past six calendar months, or a home release in the next 30 days. Theatrical dates do not count. US release information is prioritized when available, while worldwide home releases count.
- Featured titles are sorted with already-available releases newest first, then upcoming home releases nearest first. **One featured movie, then two random older/other watchlist movies**, repeated.
- Once the featured titles run out, all remaining watchlist movies are included in randomized order. If no movie qualifies for the featured category, the entire row is shuffled.
- Each title is included at most once. The whole catalog is paginated into 50-item `skip` pages instead of silently discarding movies after 50.
- Known home release information is shown using the same TV top-tab and anime-dub left-chip renderer on top of a BetterPosters base, with TMDB fallback. Historical tags include the release year; unknown data is **not** labeled as released.
- A movie without verified digital/physical release information keeps its unmodified base poster. Movies without IMDb/TMDB IDs can use their Simkl title and poster as a fallback, though third-party scraper compatibility with `simkl:` IDs is not guaranteed.

## Published paths

- Same addon: `https://simkl-nextup.github.io/account-2/manifest.json`
- New catalog: `/account-2/catalog/movie/simkl-movies-smart-shuffle-account2.json`
- Pagination: `/account-2/catalog/movie/simkl-movies-smart-shuffle-account2/skip=50.json`, `skip=100.json`, etc.
- New status only: `/account-2/status.json` → `smartShuffle`.
- Tagged posters: `/account-2/posters/smart-shuffle/`.

The static files support Stremio's `skip` catalog-extra convention. Individual Nuvio/Stremio clients may cache catalog results or may not request later pages. **Refresh-by-refresh, request-level shuffling is not possible with GitHub Pages**: the order changes only when the scheduled build completes and the client fetches the new JSON. Installing a second addon is not required; refresh/reinstall the same manifest if the client caches catalog declarations.

## Integration sequence

1. `npm run refresh` (Account 2 TV row; clears/recreates Account 2 output).
2. `npm run refresh:movies` (original Home Releases row and private TMDB cache).
3. `npm run refresh:discovery` (original global Upcoming Movies/TV rows).
4. `npm run refresh:smart` (appends only the **fifth** row).
5. `npm run verify` with `VERIFY_SMART_SHUFFLE=true`.

The only changes outside new modules are plumbing in package scripts, GitHub Actions, the output verifier, and documentation. No existing row builders, existing poster-layout code, or existing movie-release rules were changed.

## Security and limits

The generated movie list is public, just as with the existing personal rows; tokens and the private release cache are not published. This design relies on the current Home Releases refresh completing successfully before the Smart Shuffle job. Titles with missing third-party metadata may have fewer tags. Large movie lists require more poster downloads, so first builds may take longer. Pagination support depends on the client requesting Stremio `skip` extras.
