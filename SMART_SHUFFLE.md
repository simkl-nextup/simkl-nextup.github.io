# Account 2: Movies · Smart Shuffle (fifth catalog)

**Independent of all previous rows.** The new catalog is appended after TV Up Next, Home Releases, Upcoming Movies, and Upcoming TV; the root anime addon is unchanged. The existing Account 2 manifest URL remains the same.

## What the row does

- Source: the **entire Account 2 Simkl movie Plan to Watch list**, not a six-month-filtered subset.
- Every hour, the existing GitHub Actions build fetches the list and reuses the private TMDB release-date cache generated by the existing Home Releases row.
- A **featured** item is an exact match to a movie *actually published* in the existing Home Releases row. That row alone controls the six-month release window, the 30-day Coming Soon rule, US priority, theatrical exclusions, and its maximum item count. No extra release eligibility is invented for Smart Shuffle.
- Featured titles keep precisely the same order as the published Home Releases row (released newest first, then Coming Soon nearest first). **One featured movie, then two random older/other watchlist movies**, repeated.
- Once the featured titles run out, all remaining watchlist movies are included in randomized order. If no movie qualifies for the featured category, the entire row is shuffled.
- Each title is included at most once. The base catalog now includes **every** Plan to Watch movie without a `skip` manifest requirement. Optional 50-item static pagination files are still generated for direct access; they are not needed for Nuvio to discover the row.
- **Only** titles present in the existing Home Releases row receive release-date/status tags. They reuse that row's **exact final rendered poster**, so style and eligibility cannot drift. Every other randomized watchlist title always uses its **plain BetterPosters** base (TMDB/Simkl fallback) and does **not** display release tags, even if a historical or unfeatured release date is known.
- All random-slot movies outside the actual Home Releases row keep their unmodified base poster. Movies without IMDb/TMDB IDs can use their Simkl title and poster as a fallback, though third-party scraper compatibility with `simkl:` IDs is not guaranteed.

## Published paths

- Same addon: `https://simkl-nextup.github.io/account-2/manifest.json`
- New catalog: `/account-2/catalog/movie/simkl-movies-smart-shuffle-account2.json`
- Pagination: `/account-2/catalog/movie/simkl-movies-smart-shuffle-account2/skip=50.json`, `skip=100.json`, etc.
- New status only: `/account-2/status.json` → `smartShuffle`.
- Tagged posters: reused directly from the published Home Releases row; Smart Shuffle does not generate a second copy.

Nuvio compatibility: the manifest advertises an ordinary movie catalog without optional `skip` extras, because some clients do not show catalogs declaring unsupported extras. All movies are included in the base `.json`; individual Nuvio/Stremio clients can still impose their own display limits. Optional static skip files remain available. **Refresh-by-refresh, request-level shuffling is not possible with GitHub Pages**: the order changes only when the scheduled build completes and the client fetches the new JSON. Installing a second addon is not required; refresh/reinstall the same manifest if the client caches catalog declarations.

## Integration sequence

1. `npm run refresh` (Account 2 TV row; clears/recreates Account 2 output).
2. `npm run refresh:movies` (original Home Releases row and private TMDB cache).
3. `npm run refresh:discovery` (original global Upcoming Movies/TV rows).
4. `npm run refresh:smart` (appends only the **fifth** row).
5. `npm run verify` with `VERIFY_SMART_SHUFFLE=true`.

The only changes outside new modules are plumbing in package scripts, GitHub Actions, the output verifier, and documentation. No existing row builders, existing poster-layout code, or existing movie-release rules were changed.

## Security and limits

The generated movie list is public, just as with the existing personal rows; tokens and the private release cache are not published. This design relies on the current Home Releases refresh completing successfully before the Smart Shuffle job. Titles missing third-party metadata may have fewer details. The Smart Shuffle job reuses completed Home Releases posters rather than making redundant poster downloads. The client must refresh its cached manifest to pick up the fifth catalog; its own UI may limit how many tiles it displays.

## Poster Studio

Smart Shuffle intentionally has no separate poster renderer. Home Releases-featured titles reuse the *exact finished* Home Releases posters and therefore follow its Poster Studio settings. Random titles retain plain BetterPosters art, even when older release information exists. The two Upcoming discovery rows have their own separate Studio tabs and never affect Smart Shuffle.

### Theatrical-only watchlist movies (October 2026)

Randomized Smart Shuffle slots may also receive the existing Home Releases-style
**date tab + red `IN THEATERS` side chip**, but only when TMDB records a confirmed
commercial theatrical release within the past 60 days **and** no digital or
physical release has happened anywhere. The displayed date prefers a recent US
cinema premiere, otherwise a recent worldwide one. It is a *recent-release
signal*, not proof the film is playing at a particular local cinema.

The theatrical movie **does not become a Home Releases featured slot**. It
remains part of the shuffled 2-random sequence. Home Releases remains strictly
digital/physical and unchanged; its qualifying movies still reuse its exact
finished posters. Older random movies stay untagged. On a failed image fetch,
the movie stays in Smart Shuffle with its ordinary base poster rather than
vanishing or being labeled as successfully rendered. Cinematic tabs share the
current Home Releases Studio tag-size, shadow and top/side appearance settings.

### Scheduled cinema premieres (Smart Shuffle only)

Plan to Watch movies with verified TMDB theatrical/limited/premiere dates within
90 days receive a top tab such as `THEATRICAL · OCT 23` and a `COMING SOON`
side chip. Movies premiered within the last 60 days but not yet available
digitally or physically can show `IN THEATERS`. This never changes the
release → random → random ordering, never inserts the movie into Home Releases,
and never labels an older theatrical reissue as a new release. Missing dates
leave ordinary randomized posters untagged. US dates take priority.
