This commits to with the settings for all five styled rows. The Smart Shuffle row automatically reuses Home Releases posters. Saving that file starts the refresh workflow, and the new posters appear in Nuvio once it finishes (usually a few minutes).

It needs a GitHub fine-grained personal access token:

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repository.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
